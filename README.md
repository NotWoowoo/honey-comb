# honey_comb

This is a comb filter. Well... maybe not quite.

Modulate the delay time to hear a very weird effect that I can only think to describe as "viscous." This effect is caused by multiple delay times smoothly interpolating between values, causing the signal to interact with itself in strange ways.

Honey_comb can function as a standard delay or as a comb filter, but it's probably most interesting as a sound design tool.

**Important:** Yes, it's called *honey_comb* (with the underscore, all lowercase), because apparently there's already a plugin called *honeycomb*. Hopefully this differentiates the names enough to avoid chaos.

## Download

- Go to the latest [release](https://github.com/NotWoowoo/honey-comb/releases/tag/untagged-3d2498d1aaef974026d8)
- Download the zip file corresponding to your OS: Windows or Linux (X11)
- Put the VST3 and CLAP into their respective directories
  - CLAP, Windows: `C:\Program Files\Common Files\CLAP`
  - CLAP, Linux: `~/.clap`
  - VST3, Windows: `C:\Program Files\Common Files\VST3`
  - VST3, Linux: `~/.vst3`
- Scan for plugins in your DAW
